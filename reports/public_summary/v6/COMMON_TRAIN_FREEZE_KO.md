지원 모델의 축별 교집합은 한 번만 동결한다. 이후 어떤 셀이 실패해도 표본을 다시 늘리거나 추첨하지 않는다. 원본 JSONL 행과 정답은 바이트 단위로 유지하고, 표본 대체·정답 자르기·새 데이터 추가 없이 부분집합만 만든다. 71762와 MedMCQA는 V6 주 학습에 포함하지 않는다.

동결 파일의 원본 행 순서와 학습 노출 순서를 구별한다. 학습 순서는 `SHA256(canonical JSON [seed, sample_id])`의 오름차순, 동률이면 sample ID 순서로 고정한다. 축 안의 모든 모델은 같은 순서를 사용한다. 선언된 세 seed의 정확한 순서·인덱스 해시를 보존하되, 추가 seed 실행 대상은 이후 전체 validation의 family 선택으로만 정한다.

한 pass, microbatch 1·누적 16 기준 텍스트는 **500 updates / 마지막 13개**, VQA는 **124 updates / 마지막 11개**다. 마지막 배치를 반복 표본으로 채우지 않는다. 각 예제의 정답 token 평균 loss를 구하고 실제 배치 예제 수로 평균한다.
