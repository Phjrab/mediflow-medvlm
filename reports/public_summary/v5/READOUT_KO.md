# v5 진단 해석

현재 단계: 사전 고정한384건의 실제 GPU 검증 진단과 재채점·무결성 검증을 완료했다. 이전 v1~v4 결과는 보존했다.

이번에 한 일: 같은24검증문항을 두 모델의 Base/Tuned에 적용하고, 원래 지시문과 마지막 형식 지시만 한국어로 번역한 경우를16/256token 상한에서 비교했다. KorMedMCQA·AIHub71875 객관식·PubMedQA 각8개이며 KorMed는 직군별2개다. 새로운 학습이나 test 추론은 하지 않았다. `qwen3_17b`는 실행키이며 실제 모델은 Qwen3-1.7B다.

확인 결과:

| 모델·가중치 | 기존 지시16 | 기존 지시256 | 한국어 지시16 | 한국어 지시256 |
| --- | ---: | ---: | ---: | ---: |
| Qwen3-1.7B Base | 22/24 | 22/24 | 9/24 | 9/24 |
| Qwen3-1.7B 71762 Tuned | 0/24 | 0/24 | 0/24 | 0/24 |
| Qwen3-4B Base | 21/24 | 21/24 | 24/24 | 24/24 |
| Qwen3-4B 71762 Tuned | 0/24 | 0/24 | 0/24 | 0/24 |

표는 parser가 요구 형식을 받아들인 건수이며 임상 정확도가 아니다. 엄격한 문항별 정답 수와 source별 결과는 [전체 결과](RESULTS_KO.md)와 [집계 JSON](run_summary.json)에 있다. 기술 실패0,16→256 greedy prefix192/192쌍 일치, Base/Tuned native 가중치·template·dtype·같은 조건의 prompt 일치를 확인했다.

두 Tuned 모두 상한을256으로 늘려도 형식 준수가 회복되지 않았다. 기존 지시 조건에서 길이 종료는1.7B24→11건,4B24→7건으로 줄었지만 길이 상한에 걸리지 않고 끝난 응답도 strict parser에는 맞지 않았다. 따라서 이24문항의 실패를 단순히16token 부족으로만 설명할 수 없다. 한국어 번역도 Tuned를 회복시키지 않았으며, Base에서는 모델에 따라 개선·퇴보가 달랐다. 한국어 지시가 항상 유리하다고 볼 수 없다.

이 관측은 v4가 한국어 자유서술 전용 학습 뒤 형식 지시를 유지하지 못하는 현상과 부합한다. 다만 무작위 QA 연결 자체가 원인이라고 입증한 실험은 아니다. 학습 과제·문체·정답 token 노출량도 다르며, 무작위 답변의 개별 질문 관련성과 의학적 적합성은 전문가가 확인하지 않았다. 의료 추론 능력0 또는 일반적인 한국어 의료 성능 향상으로 해석하지 않는다. 작은 기존 validation 부분집합이며 blind test가 아니다.

다음 단계: 이번 진단은 종료한다. 기존 parser를 느슨하게 바꿔 v4 점수를 보정하거나, test에 맞춰 지시문·seed·checkpoint를 고르지 않는다. v4는 제공처 방식의 별도 약한 참조 실험으로 유지한다. 기존 v2 KO/MIX의 과제 혼합 실험도 보존돼 있으므로 같은 학습을 다시 돌리지 않는다. 추가 SFT를 설계한다면 검증된71875 객관식·자유서술과 기존 영어 과제의 형식 유지 목표를 명시하고,71762의 질문 관련성 검토 및 source별 노출량을 분리해야 한다. KorMedMCQA의 학습 제외는 유지한다. 이 후속 학습은 이번384건 진단에서 실행하지 않았다.

사용자가 할 일: 필수 파일·승인은 없다. 기존 전문가 검토표는 로컬 `outputs/v4/review/`에 있고 사람의 임상 검토는0건이다. 코드·자동 진단을 완료한 상태와 의학적 검토가 끝난 상태를 구분한다.
